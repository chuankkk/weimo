# 提示词模板

把下面模板里的 `{}` 替换成你的需求，直接发给带 `question-bank-builder` skill 的 AI。

## 1. 从大纲生成一套题库

```text
使用 question-bank-builder skill，为「{考试/学科}」制作一套题库。

- 目标人群：{人群}
- 大纲/教材版本：{版本}
- 总题数：{N}
- 一级题库：{2–4 个}
- 子库/章节：{列出}
- 题型配比：单选 {x}，多选 {x}，判断 {x}，填空 {x}
- 难度：{简单/中等/困难/混合}
- 输出：CSV（UTF-8，单行单元格），并用 --strict 校验通过
- 解析要说明正确依据；选择题指出错误项问题
- 原创或改编，不要大段复制受版权保护的真题

先给我蓝图和第一批 10–20 题，确认后继续。
```

## 2. 把笔记/教材整理成题库

```text
使用 question-bank-builder skill，把我提供的资料整理成闱墨题库。

资料范围：{粘贴/附件}
目标考试：{...}
题数：{N}
题型：{...}

要求：
1. 只使用资料中能支持的内容，不要编造事实；
2. 先列知识点清单和题型配比；
3. 输出 CSV，题干/选项/解析保持单行；
4. 用 skill 的 validate-bank.mjs --strict 校验；
5. 交付时说明哪些知识点资料不足、哪些题是改编。
```

## 3. 扩展现有题库

```text
使用 question-bank-builder skill，基于我现有的题库扩展 {N} 道题。

现有文件：{路径}
需要补强的子库/知识点：{...}
不要与现有题重复；保持相同的知识点命名和难度风格。
先分析现有题库的题型/难度分布，再给扩展蓝图，最后输出 CSV 并校验。
```

## 4. 修复导入失败/格式混乱的题库

```text
使用 question-bank-builder skill，诊断并修复这个题库文件：{路径}

请：
1. 运行 node .agents/skills/question-bank-builder/scripts/validate-bank.mjs "{路径}" --json；
2. 按行修复题干、题型、选项、答案、填空空数、重复题；
3. 不要改变题目原意；无法判断的题标出来问我；
4. 输出修复后的 CSV 和修复摘要（改了什么、还剩什么警告）。
```

## 5. 设计组卷蓝图

```text
使用 question-bank-builder skill，为「{考试}」设计一套 {时长} 分钟的模拟卷蓝图。

要求：
- 总分 {S} 分，题型 {单选/多选/判断/填空} 配比 {…}
- 覆盖 {子库/知识点}，难度 {…}
- 给出每个子库的题数、每题分值、建议时间
- 如果我的题库题量不够，指出缺口，不要用重复题凑数
```

## 6. 审校一批题

```text
使用 question-bank-builder skill，审校这份题库：{路径}

按 quality-rubric 的 100 分表评分；
重点检查：答案唯一性、干扰项、解析、事实错误、重复题、难度分布。
先输出问题清单（按行号），不要直接改；我确认后再生成修订版。
```

## 7. 生成 Android/Web 可直接导入的交付包

```text
使用 question-bank-builder skill，把结果整理成可导入闱墨的交付包。

- 题库 CSV
- 蓝图/知识点清单
- 校验报告（--strict）
- 3–5 行导入步骤
- 已知限制和来源说明

不要只发题目文本；文件路径要明确。
```

## 常用约束（可追加）

```text
- 题干、选项、解析中不要使用换行；CSV 单元格必须单行。
- 多选题答案用英文逗号分隔，例如 A,C,D，不要写 ABD。
- 填空题每个 ____ 对应一组答案，多个空用 ; 分隔。
- 判断题答案统一写“对”或“错”。
- 不要使用“以上都对/以上都不对”作为选项。
- 同一知识点连续出题不超过 2 道。
- 解析至少 30 字，必须说明为什么正确/为什么错误。
```
