# 闱墨导入格式（完整说明）

本文件是 `question-bank-builder` skill 的格式参考，也是应用导入逻辑的对照说明。应用版本：v2.0.0。

## 1. 导入入口

- Web / PWA：题库 → 导入导出 → 导入题库文件。
- Android：题库 → 导入导出 → 导入题库文件。
- 支持 `.xlsx` / `.xls` / `.csv` / `.json`。
- 普通题库文件会**合并**到现有数据；完整备份 JSON 会**覆盖**当前数据。

## 2. 标准表头

CSV / Excel 第一行必须是表头，顺序可变：

```csv
大题库,小题库,题型,题干,选项A,选项B,选项C,选项D,答案,可接受答案,解析,知识点,标签,难度,来源,排序号
```

- 可只写 `选项A`–`选项D`；需要更多选项时写到 `选项H`。
- 缺失的可选列按空值处理。
- 表头名会 trim；不要用合并单元格、多行表头或标题行。
- Excel 会读取**所有工作表**，每个工作表第一行都应当是表头。

### 字段别名

| 标准字段 | 应用也接受 |
| --- | --- |
| 大题库 | `rootBank`、`root_bank`、`题库`、`题库名称` |
| 小题库 | `childBank`、`child_bank`、`子题库`、`章节` |
| 题型 | `type`、`questionType` |
| 题干 | `stem`、`question`、`题目` |
| 答案 | `answer`、`correctAnswer` |
| 可接受答案 | `等价答案`、`answerAliases`、`aliases` |
| 解析 | `explanation`、`analysis` |
| 知识点 | `knowledgePoints`、`knowledge`、`考点` |
| 标签 | `tags` |
| 难度 | `difficulty` |
| 来源 | `source` |
| 排序号 | `sortIndex`、`order` |

选项列也接受 `A`/`a`、`optionA` 等写法，但 AI 应统一输出 `选项A`。

## 3. 题型

| 应用内部值 | 推荐写法 | 其他兼容写法 |
| --- | --- | --- |
| `single` | 单选 | 单选题、single、radio、1 |
| `multiple` | 多选 | 多选题、multiple、checkbox、2 |
| `judge` | 判断 | 判断题、judge、truefalse、true/false、3 |
| `fill` | 填空 | 填空题、fill、blank、4 |

AI 输出统一使用中文 `单选` / `多选` / `判断` / `填空`。

## 4. 答案规则

### 单选

```text
答案：B
```

- 恰好一个选项键。
- 选项至少 A、B 两个。
- 答案键必须在选项中存在。

### 多选

```text
答案：A,C,D
```

- 用英文逗号、中文逗号、顿号或空格分隔均可；推荐英文逗号。
- 至少要两个答案键。
- **不要写 `ABD`**：解析器会把它当成一个 token `ABD`，无法匹配选项。
- CSV 中答案含逗号时必须用双引号包裹：`"A,C,D"`。

### 判断

```text
答案：对
```

接受：`对 / 正确 / true / t / yes / y / 是 / √ / 对的`，以及对应的错/否/×/false 等。推荐统一写 `对` 或 `错`。

判断题不要填写选项。

### 填空

```text
题干：光合作用把____能转化为化学能，主要发生在____中。
答案：光能;叶绿体
可接受答案：光能|太阳能;叶绿体|chloroplast
```

- 题干中每一个空用连续两个以上下划线表示：`____` 或 `＿＿＿＿`。
- 每个空一个答案，用英文或中文分号分隔。
- 答案组数应与题干空格数一致。
- `可接受答案` 每组用 `|` 分隔等价写法，组间用 `;` 分隔；组数必须与答案组数一致。
- 不写 `可接受答案` 时，只接受标准答案（仍会做全半角/空白归一化）。
- 填空答案本身含分号时会被拆成多个空，需改写或避免。

## 5. 选项

- 只读取 `选项A` 到 `选项H`。
- 空选项会被跳过；例如只填 A、B、D，选项键就是 A、B、D，答案也必须用这些键。
- 选择题建议从 A 开始连续填写；不连续会产生警告，但不一定阻断导入。
- 判断题、填空题不要填写选项，避免 UI 出现多余选项。
- 选项文本不要以 `A.`、`B、` 开头重复键名；应用会自动显示键名。

## 6. 题库层级

- `大题库` 是一级题库；不存在时自动创建。
- `小题库` 是可选子库；不存在时自动在对应大题库下创建。
- 同名同层会复用已有题库；不同空格/标点会被当成不同名称，可能产生重复目录。
- 同一个子库名可以出现在不同大题库下；同一大题库下不要重复建同名子库。
- 导入题目会归入 `小题库`（若填写），否则归入大题库根。

## 7. 知识点、标签、难度、来源、排序号

- `知识点` / `标签`：按 `;`、`；`、`,`、`，`、`、`、`|` 拆分；建议知识点 1–3 个，标签 0–3 个。
- 不要在单个知识点内部使用逗号/顿号，否则会被拆成多个知识点。
- `难度`：1–5 的整数；缺省为 2；非法值会被应用夹到 1–5（AI 不应依赖夹取）。
- `来源`：真题年份、教材、原创/改编说明；缺省使用导入文件名。
- `排序号`：数字；缺省按导入顺序。

## 8. CSV 兼容性

闱墨的 CSV 解析器**按物理行读取**，不是完整的 RFC 4180 多行解析器：

- 一题必须在一行内。
- 单元格内不能有换行；解析需要分段时用 `；`、` / ` 或句号。
- 含逗号、引号、换行的字段必须用双引号包裹；内部双引号写成 `""`。
- 文件使用 UTF-8；带 BOM 对 Excel 更友好，不带 BOM 应用也能读。
- 空行会被忽略。
- 不要输出 Markdown 表格或 `.md` 文件冒充 CSV。

## 9. JSON 格式

推荐输出行数组：

```json
[
  {
    "大题库": "初中生物",
    "小题库": "光合作用",
    "题型": "单选",
    "题干": "光合作用主要发生在植物细胞的哪个结构中？",
    "选项A": "线粒体",
    "选项B": "叶绿体",
    "选项C": "细胞核",
    "选项D": "液泡",
    "答案": "B",
    "解析": "叶绿体含有叶绿素，是光合作用的主要场所。",
    "知识点": "光合作用;细胞结构",
    "难度": 2,
    "来源": "原创"
  }
]
```

也接受：

```json
{ "questions": [ { "...": "..." } ] }
```

**不要**输出同时含 `banks` 和 `questions` 的完整备份结构；应用会把它识别为整库恢复并覆盖当前数据。

## 10. 导入校验与报告

应用会逐行检查：

- 题干为空 → 跳过
- 题型无法识别 → 跳过
- 答案为空 → 跳过
- 单选/多选选项少于 2 个 → 跳过
- 题干 + 选项 + 答案指纹重复 → 跳过并警告
- 解析为空 → 警告
- 知识点为空 → 警告

导入结束后会显示新增、跳过、错误和警告数量。AI 交付前应先用 skill 自带校验器把错误降为 0，并检查所有警告。

## 11. 常见错误

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 导入 0 题 | 表头不是第一行 / 用了 Markdown 表格 | 用真实 CSV，表头在第一行 |
| 少了很多题 | 题干/答案为空、题型写错、选项不足 | 看导入报告逐行修复 |
| 多选题只识别一个答案 | 写成 `ABD` | 写 `A,B,D` |
| 填空题答案错位 | 答案组数与空格数不一致 | 每个 `____` 对应一组答案 |
| 判断题出现选项 | 判断题误填了 A/B | 判断题选项留空 |
| 解析/知识点丢失 | 含逗号未加引号，列错位 | 用 CSV 引号或校验器检查 |
| 整库被覆盖 | JSON 同时含 `banks` 和 `questions` | 只输出行数组或 `{questions}` |
| 题库目录重复 | 大题库/小题库名称有空格或标点差异 | 统一名称，做一次清洗 |
