# 出题质量量表

用于 AI 自检、人工抽检和题库验收。建议正式题库达到 **85 / 100** 以上；考试类题库建议 **90+**。

## 评分表

| 维度 | 分值 | 合格标准 | 常见扣分 |
| --- | --- | --- | --- |
| 大纲覆盖 | 20 | 每个章节/知识点都有题；题型覆盖大纲要求 | 只堆一个章节；缺少综合题/应用题 |
| 学科正确性 | 25 | 事实、公式、概念、选项均正确；答案无争议 | 概念混淆；旧教材结论；计算错误 |
| 答案唯一性 | 15 | 单选只有一个正确项；多选答案完整；填空可判定 | 两个选项都对；多选漏选；填空歧义 |
| 干扰项质量 | 15 | 同类别、同粒度、长度相近；错误有代表性 | “以上都对/都不对”；明显凑数；长度差异过大 |
| 解析质量 | 10 | 说明正确依据；选择题指出关键错误项 | 只写“见教材”；解析与答案矛盾 |
| 难度梯度 | 5 | 1–2 星、3 星、4–5 星都有；符合目标考试 | 全部同一难度；过难/过易 |
| 格式与完整性 | 10 | 字段完整；答案/选项/空数一致；通过 `--strict` | 缺解析/知识点；CSV 列错位；重复题 |

## 蓝图模板

出题前先写清楚：

```text
考试/学科：
目标人群：
大纲/教材版本：
总题数：
一级题库：
  - 子库 A：题数 / 题型 / 难度
  - 子库 B：题数 / 题型 / 难度
知识点：
  - ...
题型配比：单选 x%，多选 x%，判断 x%，填空 x%
难度配比：1–2 星 x%，3 星 x%，4–5 星 x%
来源与版权：
```

## 单题自检

- [ ] 题干只问一件事，没有“下列哪项不正确”与“正确”混用。
- [ ] 单选题只有一个选项能成立；多选每个正确项都必要且充分。
- [ ] 干扰项是“像真的错误”，不是明显荒谬项。
- [ ] 选项长度、语法结构大致一致；没有靠“以上都对”凑数。
- [ ] 解析解释正确依据，并至少指出一个错误项的问题。
- [ ] 知识点使用统一命名，没有同义重复（如“光合作用”和“光合”混用）。
- [ ] 难度符合目标考试，不是所有题都标 2。
- [ ] 没有与同批题目重复；同一知识点没有连续同质题。
- [ ] 来源诚实；原创/改编/真题引用标注清楚。
- [ ] 填空每个 `____` 都有且只有一组答案；等价答案组数一致。

## 人工抽检

- 每批随机抽 10%–20%，至少 5 题。
- 重点看：答案是否有争议、解析是否支持答案、干扰项是否成立、是否存在事实错误。
- 对计算题重新算一遍；对概念题查教材/大纲原文。
- 发现系统性错误时整批返工，不只修抽到的那几题。

## 常见“假质量”

- 题量很大，但同一道题换数字重复。
- 解析是题干复述，没有解释为什么。
- 选项很长，正确答案最长，形成位置/长度提示。
- 判断题全是“对”，答案分布严重偏斜。
- 知识点标签很多，但没有层级，无法用于弱项统计。
- 题目来自受版权保护的真题，却没有授权或来源说明。
